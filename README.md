## Featured Projects

### [Adaptive Medical Edge AI](https://github.com/CharalamposGiannakis/adaptive-medical-edge-ai)
Adaptive TinyViT for lung-ultrasound classification using OpenPOCUS. One shared checkpoint supports 24 width × frame-count configurations through structured pruning and knowledge distillation. Under simulated resource budgets, it completed 80% of requests versus 20% for the original fixed TinyViT; lightweight MobileNetV2 also reached 80%. Includes held-out evaluation and CPU benchmarking.

### [Expedia Hotel Search Ranking](https://github.com/CharalamposGiannakis/expedia-hotel-ranking)
Learning-to-rank system for hotel search personalization. LightGBM LambdaRank on 10M search impressions, 89 engineered features, NDCG@5 = 0.408. Within-search feature normalization, position bias analysis, and fairness auditing.

### [Transport Mode Detection](https://github.com/CharalamposGiannakis/transport-mode-detection)
Classifying six transport modes from smartphone IMU sensors with a six-rung evaluation ladder from random splits to external validation on unseen users. RF with 129 hand-crafted features reaches LOSO macro-F1 = 0.57 and generalizes to 0.60 on new participants, while a TCN collapses to 0.18 and gets worse with more data per subject.

### [Smartphone Mood Prediction](https://github.com/CharalamposGiannakis/smartphone-mood-prediction)
Next-day mood prediction from smartphone sensor data for depression monitoring. XGBoost vs LSTM on a 27-patient clinical dataset with walk-forward temporal cross-validation. Honest engagement with small-sample limitations.

### [ML Knowledge Agent](https://github.com/CharalamposGiannakis/ml-knowledge-agent)
Personal research assistant built on an OWL/RDF knowledge graph of ML literature. Extracts structured benchmark results from papers, validates them through SHACL, and answers sourced questions about method comparisons. Graph and extraction pipeline live; query agent and UI in progress.

### [AI Calendar](https://github.com/CharalamposGiannakis/ai-calendar)
AI-assisted calendar that turns natural-language input into structured events. Python, FastAPI, SQLAlchemy.
